# Operazioni manuali dopo la pubblicazione su GitHub

Il repository **massimilianobanini/benessere-numerico** è stato creato dall'autore il 14 novembre 2026.

## Dopo la pubblicazione

- Impostare `https://negbook.com/` nel Website del repository, in attesa di una pagina specifica `/benessere-numerico/`.
- Aggiungere Topics: `benessere-numerico`, `numerical-wellbeing`, `negbook`, `emotional-intelligence`, `wellbeing`, `self-assessment`, `personal-development`, `measurement`.
- Collegare il nuovo repository dal repository del Prezzo Negativo e, in futuro, da negbook.com.
- Non aspettarsi che Google Search Console permetta di richiedere l'indicizzazione degli URL originali `github.com`: la proprietà Search Console gestibile dall'autore è il proprio dominio.

## Verifica periodica

- Controllare pubblicamente che il README, la definizione e i link siano visibili su GitHub.
- Quando la pagina ufficiale del Benessere Numerico sarà pubblicata su negbook.com, sostituire il Website del repository con l'URL specifico e inserirvi collegamenti reciproci.
- Google Search Console può richiedere l'indicizzazione delle pagine del proprio dominio verificato, non degli URL github.com.
- Conservare separati il manoscritto completo del NegBook, le definizioni pubbliche e la documentazione del Prezzo Negativo.
